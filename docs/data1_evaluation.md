# Frozen data0 baseline evaluated on data1

Evaluation date: 2026-10-05T20:30:55+08:00. Generated by `evaluate.py`.

## Outcome

The submission model trained on all 121,838 data0 sites was applied to every labelled data1 site without retraining, refitting the scaler, tuning, or selecting a threshold. The complete data1 evaluation contains **90,810 sites**, **6,593 positive labels** and **84,217 negative labels** (positive prevalence: **7.26%**).

Its ROC AUC is **0.809337**, average precision is **0.334759**, and trapezoidal PR AUC is **0.334600**.

## Method

1. Load `models/data0_model.joblib`, including its data0-fitted scaler and logistic regression weights. Verify the feature specification and scikit-learn version.
2. Stream `data1/dataset1.json.gz` and calculate the same 45 label-free features used for data0: 18 signal summaries, log read count, and 26 sequence indicators. Neither label nor metadata offsets are model features.
3. Match each signal site to `data1/data.info` by `(transcript_id, transcript_position)`. Verify unique coordinates, complete signal/label matching, finite probabilities in [0, 1], and agreement between metadata read counts and observed signal read counts.
4. Predict in batches using the saved pipeline, then calculate ranking and probability-error metrics. Evaluate a constant predictor assigning the data0 positive fraction (0.044937) to each site.
5. Compare coordinates and transcript IDs against data0. Report the frozen submission model's performance on each subset below. No gene identities are inferred for transcripts missing from data0.
6. As an additional gene-separated check, apply `models/data0_evaluation_model.joblib` (trained on 98,006 sites from the original 80% gene split) to data1 sites whose transcripts map to original data0 held-out genes. These genes were absent from that model's training. This is a different model from the all-data0 submission model.

`overlapping_sites` means the same transcript and position occur in data0. `new_sites` means the coordinate pair does not occur in data0. `new_transcripts` means the transcript ID is absent from data0; this is a subset of `new_sites`, not an additional disjoint category.

For all data1 sites, the constant predictor's ROC AUC is **0.500000** and average precision is **0.072602**. Its log loss is **0.267888** and Brier score is **0.068096**. The average-precision reference equals data1 prevalence. Trapezoidal PR AUC for a constant predictor is not a suitable prevalence reference because the curve's endpoint interpolation can inflate it.

For comparison, the original evaluation model's within-data0 gene-held-out ROC AUC was **0.902878**, average precision **0.499075**, and trapezoidal PR AUC **0.498388**. This comparison involves different evaluation distributions and, for the full data1 row, a different training size. It should not be read as a controlled estimate of dataset shift.

## Overlap and independence

- **67,320 / 90,810 data1 sites (74.13%)** share transcript-position coordinates with data0.
- **23,490 sites** have new coordinates. New coordinates can still belong to genes seen during training.
- **3,432 transcript IDs** occur in both datasets; **1,019 data1 transcript IDs** are absent from data0. Absence of a transcript ID does not establish absence of its gene; data1 has no gene-ID column, and no external annotation was used.
- Among shared coordinates, **3,872 (5.75%)** have different binary labels. The files do not establish why: biological context, label generation, or other differences require source provenance. We use data1's labels as supplied and do not replace them with data0 labels.
- Label changes at shared coordinates: **2,717** changed from 0 to 1; **1,155** changed from 1 to 0.

The overall data1 score is a transfer check with substantial training-coordinate overlap, so it does not establish performance on entirely unseen genes or the hidden leaderboard. The new-transcript subset reduces transcript overlap but cannot prove gene separation. The additional evaluation-model row is separated from that model's training genes for all sites that can be mapped through data0 transcript annotations; it covers only that mapped subset. We have not verified cell-line identity, shared read molecules, or label-generation independence from the supplied files.

## Fixed 0.5 threshold diagnostic

At a probability threshold of 0.5, the full data1 evaluation gives TP **1,100**, FP **912**, FN **5,493**, TN **83,305**. Precision is **0.546720**, recall **0.166844**, and F1 **0.255665**. This threshold was not optimised and is not needed for leaderboard submission, which uses probability scores. ROC AUC measures ranking, not classification accuracy. Average precision and trapezoidal PR AUC use different integration conventions.

## Verification and reproducibility

All **90,810** metadata sites matched unique signal records and predictions. No sites were dropped. Both model-file SHA-256 hashes remained unchanged across evaluation. Models were loaded and used only for prediction; no `.fit` calls were made. Historical versions, source hashes, subset counts and numeric metrics are published in `results/data1_evaluation/metrics.json`. New evaluations write `artifacts/data1/metrics.json` by default.

Run from the project directory with its virtual environment:

```bash
.venv/bin/python evaluate.py \
  --data data/data1/dataset1.json.gz \
  --labels data/data1/data.info \
  --reference-labels data/data0/data.info.labelled
```

First run the data0 reproduction command in `docs/data0_training.md` to regenerate `artifacts/split.csv`. The defaults load the two packaged data0 models and `results/data0/metrics.json`; evaluation writes `artifacts/data1/` and this report. Historical result summaries are published in `results/data1_evaluation/`. Adjust input paths if your datasets are stored elsewhere.
